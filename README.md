# Credit Risk Model

A machine learning web application that predicts credit risk for loan applicants, built with scikit-learn and deployed via Streamlit.

## Live Demo

🔗 [credit-risk-model-hpjlk.streamlit.app](https://credit-risk-model-hpjlk.streamlit.app)

## Overview

This project builds a classification model to assess the credit risk of a borrower — predicting the likelihood of loan default based on applicant features. The model is served through an interactive Streamlit interface.

## Tech Stack

| Layer | Tools |
|-------|-------|
| ML / Modelling | scikit-learn, numpy, scipy |
| Data Processing | pandas, joblib |
| Frontend / UI | Streamlit |
| Language | Python 3.11 |

## Getting Started

### Prerequisites

- Python 3.11
- pip

### Installation

```bash
git clone https://github.com/Rajputmansi7/Credit-risk-model.git
cd Credit-risk-model
pip install -r requirements.txt
```

### Run Locally

```bash
streamlit run main.py
```
